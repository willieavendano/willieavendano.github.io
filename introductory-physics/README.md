## Overview

A first course in physics that builds physical intuition through hands-on labs,
problem-solving, and real-world applications. The math toolkit is **algebra**:
students reason quantitatively using equations, ratios, and graphs. Some
**trigonometry** (sines, cosines, and vector components) shows up where it is
genuinely useful — for example, resolving forces on an incline — but it is a
supporting tool, not a focus of the course. This is the standard, non-honors
track.
