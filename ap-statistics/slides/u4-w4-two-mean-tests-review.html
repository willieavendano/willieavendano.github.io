4.10

Carrying Out Two-Mean Tests

Last week's setups, finished with real numbers.

Paired Test · Recap

The runners, revisited

From last week: 18 runners' 5K times, measured before and after a 6-week training program. H₀: μd = 0, Ha: μd > 0 (expecting times to drop), df = 17. Now the data is in:

d̄ = 0.42 min (mean drop), sd = 0.68 min, n = 18 pairs.

Deliberately reusing last week's scenario rather than a fresh one — students should feel the continuity of "we already set this up, now we finish it," which is exactly what real problem- solving under time pressure feels like on test day.

Paired Test · KDEA

Carrying out the paired t-test

StepWhat you write
Kn = 18 pairs, d̄ = 0.42 min, sd = 0.68 min. Random: stated random selection. Independent: 18 runners < 10% of all runners. Normal/Large Sample: differences reported roughly symmetric, no outliers.
Dμd = true mean difference (before − after). H₀: μd = 0, Ha: μd > 0
Eone-sample t-test on the differences, df = 17
At = 0.42 / (0.68/√18) = 0.42/0.160 ≈ 2.620
p-value ≈ 0.009 (one-sided, df = 17, calculator)
0.009 < 0.05 → reject H₀

Convincing statistical evidence that mean 5K time decreased after the training program.

The one-sample machinery from Week 1–2 is doing all the work here — the only "paired" thing about this problem was the very first step (subtracting to get the differences), which already happened before this table starts. That's the payoff of the paired framework: after the subtraction, it's a procedure they've run many times.

Two-Sample Test · Recap

Two review methods, revisited

From last week: comparing mean quiz scores between two unrelated groups using different review methods. H₀: μ₁ − μ₂ = 0, Ha: μ₁ − μ₂ ≠ 0. Now the data is in:

Method 1: n₁=26, x̄₁=78.4, s₁=9.2. Method 2: n₂=24, x̄₂=82.1, s₂=8.5.

Same continuity move as the paired example — the setup already happened last week. Worth pointing out this is a two-sided test, unlike the one-sided paired test, so students see both directions of hypothesis in the same day.

Two-Sample Test · KDEA

Carrying out the two-sample t-test

StepWhat you write
KMethod 1: n₁=26, x̄₁=78.4, s₁=9.2. Method 2: n₂=24, x̄₂=82.1, s₂=8.5. Random: both randomly assigned. Independent: both groups <10% of enrollment, and no student is in both groups. Normal/Large Sample: both n close to 30, roughly symmetric score distributions.
Dμ₁ − μ₂ = true difference in mean quiz score. H₀: μ₁ − μ₂ = 0, Ha: μ₁ − μ₂ ≠ 0
Etwo-sample t-test, df ≈ 47.8 (technology, Welch)
ASE = √(9.2²/26 + 8.5²/24) ≈ 2.503
t = (78.4 − 82.1)/2.503 ≈ −1.478
p-value ≈ 0.146 (two-sided, technology)
0.146 ≥ 0.05 → fail to reject H₀

NOT convincing evidence of a difference in mean quiz scores between the two review methods — NOT "accept H₀."

Deliberately the opposite conclusion from the paired example — a fail-to-reject result. This is the moment to re-drill the exact wording rule from Week 2: "not convincing evidence" is correct, "the methods produce the same scores" or "we accept H₀" are both banned phrasings even though the p-value came out large.

The Big Picture

Unit 4 is one story, not four topics.

Sampling distributions → the t-distribution → intervals → tests, for one mean and then two

The Big Picture · 1 of 1

One tool, applied to one mean, then two

1
Sampling distributions
Shape (CLT), center, and spread of x̄ — and later of x̄₁ − x̄₂. This is where the standard error comes from.
2
The t-distribution
We estimate σ with s, so we use t instead of z. df = n−1 for one sample; technology for two. This is why the interval is wider than z would give.
3
Confidence intervals
Estimate ± (t* · SE), for one mean or a difference of two. Compare the interval to a claimed value, or to zero.
4
Hypothesis tests
Same conditions, same t-distribution — now with a test statistic and a p-value. Paired collapses to one-sample; independent stays two-sample. Same protocol, formalized.

There's no separate "two-mean formula bank." It's the same four steps, run twice, with one extra design question: paired or independent?

Each tile builds on the one before it, same structure as the physics Unit 1 concept map. Point explicitly: if a student can do step 3 (one-mean CI from Week 1) and knows the paired-vs- independent test from Week 3, step 4 (today's carrying-out work) is just finishing what was already set up. The chip is the takeaway — say it aloud and leave it on screen.

Common Test Traps · 1 of 4

Trap #1: z vs. t confusion

The decision is about whether σ is known — not about how large n is, and not about which formula "feels" faster.

The trap

Students default to z because it's what they remember from Unit 3, or because a large n makes t and z numerically close. On this exam, σ is essentially never given for a mean — if you're not told σ, you're using t.

Common Test Traps · 2 of 4

Trap #2: df errors

Three different degrees-of-freedom rules live in this unit — mixing them up is one of the most common test errors:

Proceduredf
One-sample t (interval or test)n − 1
Paired t (after computing differences)npairs − 1
Two-sample independent tfrom technology (Welch) — never hand-computed

A paired df of npairs − 1 is easy to confuse with a two-sample df of n₁ + n₂ − 2 — that pooled formula does not apply here.

The n₁+n₂−2 pooled-df formula students may encounter outside this course (or in old materials) assumes equal population variances, an assumption this course does not make — flag explicitly that it is NOT the two-sample df rule taught here, since seeing it elsewhere is a real source of confusion.

Common Test Traps · 3 of 4

Trap #3: Paired vs. two-sample misidentification

The highest-stakes error in this unit — it changes the parameter, the standard error, and the df, all at once.

The test-day check

Before writing E, ask: does the same subject or matched unit appear in both columns of the data? Yes → paired, subtract first, one-sample t. No → independent, two-sample t.

Common Test Traps · 4 of 4

Trap #4: Context-free conclusions

A correct p-value with no context sentence is an unfinished answer — same rule as a kinematics answer with no unit.

Banned words

"Prove" — statistics never proves anything, it provides evidence. "Accept H₀" — a large p-value means "fail to reject," not "the null is true."

The required phrase: "convincing statistical evidence that…," followed by the actual claim, in context, with units.
