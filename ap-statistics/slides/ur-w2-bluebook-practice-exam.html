Act I · The Digital Room

Know the room before you solve in it.

Bluebook changes the mechanics, not the statistics.

This divider is a reset: the test still asks students to reason with data, design, probability, inference, and regression. The digital environment adds navigation and typing decisions. We practice those decisions now so they do not compete with the mathematics later.

Bluebook · 1 of 4

Read the screen as a set of stations.

1
Question pane
Read the prompt, examine any graph or table, and identify the task before touching the answer area.
2
Response area
Choose, enter, or type the response. Statistical notation can be written in clear words when a symbol is awkward.
3
Navigation rail
Move between questions, mark a question for review, and return without losing your place.
4
Tools menu
Open only the calculator, reference material, or display setting you need. Close it before reading the prompt again.
Bluebook labels and placement can change as the platform is updated, so do not promise students an exact pixel map. Teach the stable mental model: prompt, response, navigation, tools. Students should practice locating each station in the current school test environment.

Bluebook · 2 of 4

Your navigation loop: read, decide, mark, move.

MoveWhat you doWhy it matters
ReadRead the whole stem and inspect every display before calculating.Prevents solving the wrong statistical question.
DecideChoose now, or name the missing step before moving on.Protects time from a two-minute spiral.
MarkFlag uncertainty and write a two-word reminder if the screen permits.Creates a return path instead of a vague worry.
MoveContinue. Return to marked questions with remaining time.Every question gets a chance to earn points.

A marked question is a plan, not a failure.

Bluebook · 3 of 4

Use tools to reduce friction, not to outsource thinking.

▣
Embedded calculator
Use it for arithmetic, distributions, regression output, and checks. Know which values you need before opening it.
≈
Reference resources
Use the provided reference information as a lookup, not as a substitute for identifying the procedure.
↺
Display controls
Adjust what improves readability, then return attention to the data, conditions, parameter, or claim.
The symbols are visual anchors, not claims about the exact current icon set. During setup, have students open each available tool once, close it, and explain when they would use it. The common failure mode is opening a calculator before deciding whether the question is about a parameter, a probability, or a claim.

Bluebook · 4 of 4

Type statistical notation so a reader cannot misread it.

When symbols are easy:

  • Use subscripts and superscripts when the editor supports them.
  • Keep labels attached: p̂, μ, σ, H0.
  • Use parentheses around a computed expression.

When typing is awkward:

  • Write words: “the population proportion” or “the slope of the regression line.”
  • State the number, unit or context, and conclusion.
  • Never let a missing glyph become a missing explanation.

Clarity beats clever notation.

Do not teach a secret keyboard code. Practice the exact response editor students will use and insist on readable labels. A response can be statistically correct without being typographically fancy; the non-negotiable is that the reasoning and conclusion are unambiguous and in context.

Practice Exam Day · 1 of 3

One sitting. Three deliberate phases.

I
Launch
Device check, sign in, confirm tools, read directions, and settle into the interface before the clock matters.
II
Run
Complete the digital practice exam under realistic conditions. No answer sharing. Use the same timing habits as test day.
III
Close
Submit, record process notes while fresh, and leave the self-score for the workshop. Do not immediately autopsy every miss.

Simulation first. Diagnosis second.

Preserve the psychological order: students need one uninterrupted simulation before discussing results. Collect a brief exit note after submission—where time ran short, where tools caused friction, and where confidence was low—without turning it into an answer key.

Practice Exam Day · 3 of 3

When a question resists, change the move.

K
Name what is visible
List the data, design, conditions, and variables you actually have. Re-read the display.
D
Name the target
Is the question asking for a parameter, probability, interval, test decision, model feature, or claim?
E
Choose the bridge
Select the procedure, formula, or simulation logic that connects the information to the target.
A
Compute and conclude
Show the calculation, then state what it means in the setting. If stuck, mark the missing bridge and move.

Stats KDEA: K = data/design/conditions · D = target · E = procedure/formula · A = compute + context

Act II · Evidence, Not Vibes

Score the reasoning you can see.

The self-score is a workshop in evidence, not a verdict.

Students often turn a first practice score into an identity statement. Interrupt that move. The useful product is a map of which evidence was present, absent, or unclear. That map will determine next week's targeted gap review.

FRQ Workshop · 1 of 5

The new FRQ format rewards visible statistical reasoning.

Point in the 10-point formatEvidence to look for
1–2 IdentifyNames the variable, design, parameter, or question in the setting.
3–4 Set upStates conditions, hypotheses, procedure, model, or calculation that fits the task.
5–7 WorkShows a correct computation, interval/test structure, probability reasoning, or model interpretation.
8–10 ConcludeAnswers the question in context, with direction, evidence, and a justified limitation when needed.

Do not award a point because an answer “looks sophisticated.” Find the evidence.

Use the official scoring guidance attached to the practice form. This slide is a student-facing scaffold, not a replacement for that guidance. Avoid reproducing secure College Board material. The point bands are a memory aid for sorting visible evidence, not a claim that every prompt awards points in identical chunks.

FRQ Workshop · 2 of 5

Translate every response through statistics KDEA.

KDEAStatistics mappingTeacher check
K KnowData, design, variables, conditions, and relevant context.Did the response use the information the prompt supplied?
D Don’t knowThe parameter, probability, comparison, decision, or claim sought.Can a reader point to the exact question being answered?
E EquationsProcedure, formula, model, simulation plan, or inference conditions.Does the method fit the design and target?
A AlgebraCompute, interpret, and conclude in context.Does the final sentence say what the result means here?
This is the bridge from the house protocol to AP Statistics. Students should not force every response into four visible headings, but the four questions should be present in their thinking. In the workshop, ask them to underline evidence for each move rather than rewrite the response wholesale.

Self-Scoring Workshop · 3 of 5 · Timing

Score in passes, not in one emotional sweep.

8m
Pass 1 · Read
Read the prompt and your response. Circle places where evidence is visible. Do not score yet.
20m
Pass 2 · Match
Use the scoring guidance. Mark earned, not-earned, and unclear evidence for each point.
12m
Pass 3 · Diagnose
Tag the missing move: K, D, E, A, communication, or timing. Pick one next action.

Timing eyebrow: 40 minutes total · work silently first, calibrate second

Keep the first pass silent so students do not borrow a neighbor's interpretation. During calibration, compare evidence and language, not just totals. If the class period is shorter, assign one FRQ for a full workshop and collect the rest as a structured follow-up.

Self-Scoring Workshop · 4 of 5

Use three labels: earned, not earned, unclear.

LabelUse it when…Next move
EarnedThe response contains the required evidence and the setting is clear.Record the evidence in a short phrase.
Not earnedThe needed evidence is absent or the reasoning does not support the claim.Tag the missing K, D, E, or A move.
UnclearThe idea may be present, but notation, wording, or context prevents a confident read.Rewrite one sentence so a reader can verify it.

Unclear is useful data. It is a communication gap, not a character judgment.

Self-Scoring Workshop · 5 of 5

Make the missing evidence specific.

K?
Context and conditions
Did I identify the data, design, variable, or condition that controls the method?
D?
Target and claim
Did I answer the quantity or claim the prompt actually asked for?
E?
Procedure and model
Did I name and justify a method that matches the design, or did I calculate first?
A?
Computation and context
Did I show the work and finish with a sentence that interprets the result here?
Have students write one evidence phrase per tag. “I need to study inference” is too broad to drive a useful review block. “I named the interval but never stated the parameter in context” is actionable and can be matched to a specific next-week task.

After the Score

Your score becomes a gap map.

  • Content gap — I did not know the statistical idea or procedure.
  • Selection gap — I knew tools but chose the wrong one.
  • Communication gap — the idea was present but not visible.
  • Process gap — reading, navigation, or calculator friction.
  • Timing gap — the last points were never attempted.
  • Strength — evidence I can reuse on the real exam.

One response can have more than one tag. Choose the tag that changes the next action.

Let students choose a primary tag and an optional secondary tag. The primary tag should be the one that changes what they do next week. This prevents a long list of vague weaknesses and creates a manageable targeted review plan.

  • During — use read / decide / mark / move; protect checkpoints; type clearly.
