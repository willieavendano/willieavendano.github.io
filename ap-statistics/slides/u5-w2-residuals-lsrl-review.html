A model is not finished when you calculate it. Check the residuals and explain the context.

Establish the finish line: students should be able to read an output block, calculate or interpret a residual, judge whether a linear model is appropriate, and communicate a conclusion in context. A common failure mode is treating a small residual as proof that the model is good; residuals are diagnostics across the whole plot, not a single-score verdict.

Act I · Diagnostics

Residuals tell the model's story.

Observed minus predicted. Then look for the pattern.

Keep the act break short. The key transition is from describing the original scatterplot to checking what the fitted line leaves behind. Students often think residual means “error” in a moral sense; frame it as signed vertical difference, with positive and negative values carrying information.

Residuals · 1 of 4

Residual = observed − predicted

e
residual
e = y − ŷ: actual response minus the value predicted by the LSRL.
+
above the line
Positive residual: the point is above the model's prediction.
−
below the line
Negative residual: the point is below the model's prediction.
0
on the line
Zero residual: observed and predicted responses match.

Sign first. Context second. A residual is measured in the response variable's units.

Residuals · 2 of 4

Residual plots should look like aimless noise.

What we want
  • roughly centered around 0
  • no curve or wave
  • similar vertical spread across x
What a pattern says
  • curve → linear form misses structure
  • fan → changing variability
  • isolated point → investigate an outlier

“Random” does not mean “perfectly flat” or “every point near zero.” It means no systematic structure remains.

Students often over-read a residual plot and demand a horizontal line with every point at zero. Model the language “roughly centered, no clear pattern, similar spread.” Also distinguish an outlier in the original scatterplot from an unusual residual: the residual plot helps reveal both, but the context determines whether the point is a data error, an influential observation, or a real case.

Residuals · Turn & Talk · 8 minutes

Read the plot before you trust the line.

Partner prompt
  1. Sketch or inspect a residual plot for the model predicting commute time from distance.
  2. Describe center, spread, and any visible structure.
  3. Decide whether a linear model is reasonable. Use evidence from the plot.

Sentence frame: “The residuals are ___, so a linear model is ___ because ___.”

Do not supply the plot's conclusion on this slide. Listen for students using “the correlation is high” as their only justification; redirect them to residual evidence. If students say “the model is wrong” because one point is far from zero, ask whether the rest of the plot shows a pattern. The assessment target is a defensible diagnostic statement, not a magic cutoff.

Worked Example · KDEA

One residual, all four moves

A model predicts a student's quiz score from study time. For one student, the observed score is 18 points and the model predicts 24 points.

StepWhat you write
KObserved response y = 18 points; predicted response ŷ = 24 points.
DResidual e, in points; explain whether the model over- or under-predicted.
Ee = y − ŷ = observed − predicted.
Ae = 18 − 24 = −6 points. The model over-predicted this student's score by 6 points.

The final sentence is in context. In AP Statistics, an answer without context is like an answer without units.

This is the model example, so the arithmetic is intentionally visible. Emphasize the order in the subtraction: observed minus predicted, never the reverse. A negative residual is not “negative error” to erase; it says the prediction was too high. Ask students to translate the sign before moving on.

Residuals · Quick Check · 6 minutes

Which residual plot would you keep?

A
random cloud
Residuals bounce around zero with similar spread.
B
curved band
Residuals start positive, dip negative, then rise positive.
C
fan shape
Residual spread grows as the explanatory variable increases.
D
one extreme
Most residuals are small; one is far from zero.

Choose one for a linear model, then name the concern you would investigate for the other three.

This is intentionally an assessment-style prompt without an answer key. Have groups defend a choice using the three-part language: center, structure, spread. Accept “A is the best candidate” rather than “A proves the model is correct.” If time permits, ask which pattern would make predictions less equally reliable across the x-range; students should connect the fan to changing spread.

Act II · Least Squares

Read the line. Then read the output.

The equation is only one line of evidence.

Transition from diagnostics to the fitted model's numerical summary. Students commonly read an output block as a list of unrelated numbers; the next slides give each number a job and a unit or context.

LSRL · 1 of 4

The LSRL predicts the response.

Model

ŷ = a + bx

  • b is the slope: predicted change in response for a one-unit increase in explanatory variable.
  • a is the y-intercept: predicted response when x = 0, if that value is meaningful.
  • ŷ is a predicted response, not an observed score.

Always name both variables and the units before interpreting slope or intercept.

The most common slope error is “y goes up by b” with no reference to x or units. Require the full structure: for each one-unit increase in x, the predicted y changes by b response units. The intercept can be mathematically valid but contextually meaningless when x = 0 is outside the data or impossible.

LSRL · 2 of 4

r2 and s answer different questions.

r2
variation explained
The percent of variation in the response explained by the linear model with the explanatory variable.
s
typical prediction error
Typical vertical distance between observed responses and the LSRL, in response-variable units.

Do not swap them: r2 is a percent; s is a typical distance.

Students often say “r-squared is the percent of y” or “s is the error rate.” Tighten both: r² is the proportion of variation in the response accounted for by the linear model, while s is measured in the response units and describes typical residual size. Neither statistic by itself proves causation or guarantees accurate predictions for every individual.

LSRL · 3 of 4

Every output number has a job.

a
intercept
Predicted response at explanatory value 0, if meaningful.
b
slope
Predicted response change per one unit of x.
r2
fit summary
Percent of response variation explained by the linear model.
s
residual spread
Typical prediction error in response units.

Computer output is a translation task: number → statistic → context.

Worked Example · KDEA

Translate a regression output

A model predicts weekly sales (y, dollars) from advertising spend (x, dollars): ŷ = 1200 + 3.5x, r2 = 0.64, and s = 180 dollars.

StepWhat you write
KEquation, r2 = 0.64, s = 180 dollars; x = advertising spend, y = weekly sales.
DInterpret slope, r2, and s in context.
EUse the meanings: slope → predicted change; r2 → explained variation; s → typical residual size.
AFor each extra advertising dollar, predicted weekly sales increase by 3.5 dollars. The model explains 64% of sales variation. Predictions typically miss by about 180 dollars.
Make students say “predicted” for the slope; this is not a causal statement. The r² interpretation must identify variation in the response and the linear model. The s interpretation must use response units. The values are exact as supplied in the prompt; the 64% conversion is an interpretation of 0.64, not a rounded calculation, so no approximation symbol is needed.

LSRL · Turn & Talk · 10 minutes

Output reading without the calculator fog

Write three sentences

For a model predicting a plant's height in centimeters from days since planting, the output reports slope 1.8, r2 = 0.81, and s = 4.2 cm.

  1. Interpret the slope with both variables and units.
  2. Interpret r2 as a percent of response variation.
  3. Interpret s as typical prediction error.

No “strong relationship” sentence unless the prompt asks for a description of association.

This is a practice item, so do not reveal sample sentences on the slide. Circulate for the three traps: missing “predicted” in the slope sentence, treating 0.81 as 0.81%, and giving s in days instead of centimeters. If students finish early, have them explain why the intercept would need a separate context check before interpretation.

Act III · Unit Review

Make every claim earn its context.

Residuals, models, output, communication.

This act break signals the shift into test preparation. The unit review is not a new topic dump; it is a retrieval sequence that asks students to connect a graph, an equation, a diagnostic, and a sentence.

Review Map

Five moves for the Unit 5 Test

The six tiles are balanced in a 3-by-2 grid. Ask students to point to the move they most often skip. Usually it is diagnose or communicate. Reinforce that KDEA is the workflow: K is data/design/conditions given; D is the parameter, probability, or claim sought; E is the procedure or formula; A is compute and conclude in context.
