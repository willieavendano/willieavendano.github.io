# Literature and source discovery

Start with the school library catalog and scholarly databases available through the school. Search combinations of a work title, David Lynch, a specific formal feature, and a critical framework. Treat interviews as accounts of the filmmaker's perspective, not proof of audience response or the only valid interpretation.

Record searches, including unsuccessful ones. Separate primary works, scholarly interpretations, and contextual sources. Verify author, title, publisher or journal, year, page numbers, and stable link before citing.
