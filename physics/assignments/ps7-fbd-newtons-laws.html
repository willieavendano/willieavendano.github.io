How to work this set. Every force problem starts with a free-body diagram: isolate the object as a dot, draw every force acting on it (nothing it exerts on anything else), label each arrow with its symbol. Then KDEA with ΣF = ma — or ΣF = 0 if the velocity isn't changing. Force unit: N = kg·m/s², exactly as Unit 0 promised.
